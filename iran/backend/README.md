# زیرساخت سامانه «ایران» - مرحله اتصال موتور حقوقی

این پوشه، طرح اولیه backend است و هنوز روی Supabase اجرا یا deploy نشده است.

## اجزای این مرحله
- `schema.sql`: جداول منابع حقوقی، قطعات اسناد، گفتگوها، پیام‌ها و متادیتای اسناد کاربران.
- `../supabase/functions/legal-assistant/index.ts`: Edge Function احراز هویت‌شده برای جست‌وجوی مستندات و فراخوانی مدل زبانی.

## ترتیب راه‌اندازی
1. یک پروژه Supabase مستقل با نام `Iran Legal AI` بسازید؛ دیتابیس Amlak-iman نباید برای این داده‌ها استفاده شود.
2. فایل `schema.sql` را فقط در پروژه مستقل اجرا کنید.
3. Edge Function با نام `legal-assistant` را deploy کنید و `verify_jwt=true` باقی بماند.
4. Secrets سمت سرور را تنظیم کنید: `AI_API_KEY`، `AI_MODEL` و در صورت نیاز `AI_API_URL`.
5. احراز هویت Supabase برای کاربران فعال شود؛ در نسخه عمومی می‌توان ورود پیامکی را اضافه کرد.
6. منابع رسمی حقوقی، پس از کنترل اصالت، تاریخ اعتبار و نشانی رسمی، در `legal_sources` و `legal_chunks` وارد شوند.

## ملاحظات مهم
- تابع فقط برای کاربر احراز هویت‌شده پاسخ می‌دهد.
- RLS گفتگوها و اسناد را به مالک آن‌ها محدود می‌کند.
- منابع حقوقی فقط در وضعیت `published` برای جست‌وجوی عمومی قابل مشاهده‌اند.
- سرویس فعلاً بازیابی متنی (Full-Text Search) دارد؛ جست‌وجوی برداری، OCR و پردازش اسناد در مرحله‌های بعد اضافه می‌شوند.
- بدون منابع رسمی واردشده، سامانه نباید ادعای پوشش کامل قوانین ایران کند.
- قبل از عرضه عمومی، rate limit، کنترل هزینه مدل، مانیتورینگ، تست نفوذ و بررسی حقوقی داده‌ها لازم است.
