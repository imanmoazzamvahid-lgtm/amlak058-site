# اپلیکیشن اندروید املاک ۰۵۸

اپلیکیشن مستقل Native با Kotlin و Jetpack Compose است و از WebView استفاده نمی‌کند.

## امکانات نسخه ۰.۲
- دریافت آگهی‌های تأییدشده از جدول موجود public.properties
- جست‌وجوی عنوان، محله و نوع ملک و فیلتر دسته‌بندی
- نمایش جزئیات آگهی و نشان‌کردن آگهی‌های دلخواه
- ورود با شماره موبایل و کد یک‌بارمصرف Supabase Auth
- ثبت آگهی با وضعیت pending برای بررسی مدیر
- بارگذاری حداکثر ۸ تصویر در باکت خصوصی property-images
- مشاهده آگهی‌های حساب کاربر و وضعیت انتشار
- ساخت خودکار APK آزمایشی با GitHub Actions

## امنیت
- فقط کلید Publishable در برنامه قرار می‌گیرد؛ هیچ service_role یا secret در کلاینت نیست.
- آگهی‌ها با فهرست صریح ستون‌های عمومی دریافت می‌شوند و ستون تلفن در درخواست عمومی خوانده نمی‌شود.
- ثبت آگهی به کاربر واردشده محدود است و وضعیت اولیه آن pending است.
- تصاویر در پوشه pending و با سیاست RLS موجود بارگذاری می‌شوند.

## ساخت APK
در Android Studio نسخه سازگار با AGP 8.13.2 پوشه android را باز کنید.
برای ساخت محلی: gradle -p android assembleDebug
خروجی: android/app/build/outputs/apk/debug/app-debug.apk

Workflow شاخه android-app پس از هر تغییر در پوشه android اجرا می‌شود و APK آزمایشی را به‌صورت artifact نگه می‌دارد.
