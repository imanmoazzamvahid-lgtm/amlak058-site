# اپلیکیشن اندروید املاک ۰۵۸

این پوشه پروژه مستقل اندروید با Kotlin و Jetpack Compose است؛ نسخه وب‌سایت داخل WebView قرار نگرفته است.

## وضعیت فعلی
- پوسته بومی اندروید و پیمایش پایین صفحه
- صفحه خانه با جست‌وجو و دسته‌بندی‌های اولیه
- صفحات اولیه ثبت آگهی، نشان‌شده‌ها و حساب کاربری
- هنوز به Supabase متصل نیست و آگهی نمونه یا ساختگی نمایش نمی‌دهد

## ساخت APK
پروژه را در Android Studio (نسخه سازگار با Android Gradle Plugin 8.7.3) باز کنید و اجازه دهید Gradle Sync انجام شود. سپس از مسیر Build > Build APK(s) خروجی بگیرید.
