# گزارش کشف پیکره‌ها و مسیر دسترسی حقوقی ایران

## ۱. سامانه ملی قوانین و مقررات و واسط غیررسمی qavanin-mcp

مخزن عمومی sepehr071/qavanin-mcp خود را یک MCP server غیررسمی و فقط‌خواندنی برای qavanin.ir معرفی می‌کند. README آن ادعا می‌کند می‌تواند در حدود ۱۶۸ هزار سند شامل قوانین، مقررات، آرای قضایی و نظریات حقوقی جست‌وجو کند، متن یک ماده یا متن قانون در تاریخ گذشته را بخواند، اصلاحات را دنبال کند و اسناد مرتبط را بیابد.

این عدد و قابلیت‌ها در این سند به‌عنوان ادعای README یک ابزار ثالث ثبت می‌شوند، نه آمار رسمی تأییدشده پایگاه. ابزار به‌صراحت غیررسمی و وابسته به HTML وبگاه معرفی شده و README از کندی، خطا و احتمال نادیده گرفتن فیلترها یاد می‌کند.

کد مخزن با MIT منتشر شده است. مجوز MIT کد ابزار را پوشش می‌دهد، نه محتوای قوانین و اسناد وبگاه qavanin.ir. بنابراین نباید از مجوز کد نتیجه گرفت که داده‌ها برای بازنشر یا آموزش مدل آزادند.

تصمیم ایران: از مستندات این ابزار برای فهم ساختار جست‌وجو، تاریخچه ماده و روابط سندی استفاده پژوهشی می‌کنیم؛ محصول نهایی به ابزار ثالث وابسته نخواهد شد. برای هر استفاده از داده، منبع اصلی، شرایط وبگاه، URL، زمان دریافت، hash و وضعیت حقوقی همان سند ثبت می‌شود.

مخزن: https://github.com/sepehr071/qavanin-mcp
مجوز کد: https://github.com/sepehr071/qavanin-mcp/blob/main/LICENSE
سامانه اصلی: https://qavanin.ir

## ۲. پیکره قوانین ایران در Hugging Face

صفحه amirxo13/iran-legal-corpus می‌گوید متن کامل قوانین گردآوری‌شده از اختبار با regex استخراج و به ماده، اصل، تبصره، بند و ساختار فصل/باب شکسته شده است. در صفحه، فایل‌هایی مانند catalog.json، index.json، laws.jsonl و articles.jsonl معرفی شده و حجم نمایشی در بازه ۱K<n<10K قرار دارد. مجوز با عنوان other نمایش داده می‌شود.

این مجموعه برای یافتن نام قانون‌ها، مقایسه ساختار مواد و کشف موارد مفقود ارزش پژوهشی دارد؛ اما اختبار منبع ثانویه است و برچسب other شرایط بازنشر تجاری و آموزش مدل را روشن نمی‌کند. بنابراین تا بررسی فایل مجوز، نسخه dataset و منشأ هر سند، از آن برای corpus canonical یا آموزش استفاده نمی‌کنیم.

منبع: https://huggingface.co/datasets/amirxo13/iran-legal-corpus

## ۳. Persian Legal Knowledge Base

صفحه Hugging Face این مجموعه را با مجوز mixed-per-record و اندازه کمتر از هزار رکورد معرفی می‌کند. README مجموعه از ۳۷ رکورد و ۲۶ پرسش چندگزینه‌ای یاد می‌کند و هشدار می‌دهد برخی متن‌های قانونی گزیده/تلخیص‌شده‌اند و برخی منابع هنگام ساخت قابل دسترسی نبوده‌اند. در زمان بررسی، viewer مجموعه با DatasetGenerationError و CastError مواجه بود.

نتیجه: این مجموعه برای الگوی provenance، وضعیت اعتبار، caveat و طراحی RAG مفید است؛ اما متن abridged نباید در پایگاه مواد کامل یا آموزش استفاده شود.

منبع: https://huggingface.co/datasets/sosa123454321/persian-legal-kb

## ۴. پروژه دانشگاهی Sharif Legal Case RAG

README پروژه NLP-Final-Projects/legal_case_rag ادعا می‌کند حدود ۵٬۸۸۲ ماده/حکم قانونی استخراج شده و حدود ۲۵ هزار رأی قضایی گمنام‌سازی‌شده از سامانه ملی آرای قضایی جمع‌آوری شده است. این گزارش یک سرنخ روش‌شناختی مهم است، اما مجوز MIT مخزن نرم‌افزار به‌تنهایی حق استفاده از داده‌های جمع‌آوری‌شده را تعیین نمی‌کند. منشأ، تاریخ دریافت، شرایط سامانه، مجوز داده و کیفیت گمنام‌سازی باید جداگانه ممیزی شوند.

نتیجه: پروژه برای مطالعه روش استخراج و ارزیابی معماری RAG قابل بررسی است؛ داده‌های آن تا پایان ممیزی وارد corpus نمی‌شوند.

منبع: https://github.com/NLP-Final-Projects/legal_case_rag

## ۵. وضعیت دسترسی مستقیم در این نوبت

درخواست مستقیم به رکورد شناخته‌شده قانون مدنی در qavanin.ir با شناسه IDS=12021850837713548188 در ابزار وب پاسخ HTTP 503 داد. بنابراین فایل رسمی تازه‌ای در این نوبت دریافت و hash نشده است. نتیجه، تأخیر در دریافت است؛ نه اثبات نبود سند.

## ۶. تصمیم اجرایی

۱. از فهرست ۳۲ عنوان قانون پایه در model_knowledge_seed.csv برای کشف و اولویت‌بندی استفاده شود.
۲. از qavanin-mcp و پیکره‌های ثانویه فقط برای کشف شناسه و مقایسه استفاده پژوهشی شود.
۳. هیچ متن کامل ثانویه بدون مقابله با منبع اولیه به‌عنوان متن رسمی ذخیره نشود.
۴. هیچ رکورد با حقوق استفاده نامعلوم وارد آموزش نشود.
۵. محصول جست‌وجوی حقوقی، ابتدا روی اسناد رسمی دریافت‌شده و مجاز ساخته شود؛ آموزش مدل پایه مسیر جداگانه و مستقل است.
